# Specifications

An index of the design/specification documents for the features added on top of upstream Veloren in this repository. See [Setup.md](Setup.md) for how to build and run the game itself.

## Available specs

- [Terminal](specs/Terminal.md) — Specification for the semi-transparent, real-shell terminal window added to voxygen's debug egui UI.
- [OS Dungeon](specs/OsDungeon.md) — Specification for the feature that renders the server's filesystem as a walkable dungeon inside Veloren's own 3D game world.
- [Tracer](specs/Tracer.md) — Specification for the structured (JSON Lines) debug logger that lets server-generated results be verified without screenshots.
- [sec-veloren Distribution Layout](SecVeloren.md) — How code is distributed via the `fujimoon/sec-veloren` GitHub repository while keeping large assets on GitLab's Git LFS.
